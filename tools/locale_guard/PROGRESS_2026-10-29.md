`LocaleGuard_Safe.bat` komutları:

1. Adayları, manifestleri, 46 dosyayı ve 316 hücreyi doğrula (sadece okuma).
2. İlerlemeyi `.locale_guard/checkpoints/` altında hash'li bir JSON ile kaydet.
3. Locale Guard Python birim testlerini çalıştır.
4. Gerçek `tr/` dosyalarına dokunmadan 46 dosyalık **izole test uygulaması** oluştur: `.locale_guard/test_apply_master_tr_aa529ec168d1/tr/`.
5. Git durumunu görüntüle.
6. Artefakt yollarını göster.

Komutlar:

```powershell
python -B -m unittest discover -s tools\locale_guard\tests -v
python -B -m tools.locale_guard.master_tr_rehearsal status --root .
python -B -m tools.locale_guard.master_tr_rehearsal checkpoint --root .
python -B -m tools.locale_guard.master_tr_rehearsal rehearse --root .
```

### Koruma sınırları

- Kodda **canlı apply fonksiyonu yoktur**; manifest `apply_authorized=false` ve `human_approved_count=0` durumunda kalır.
- Master/TR hedefleri ve önizleme dosyaları exact SHA-256 ile doğrulanır.
- UTF-8/CP1254, BOM, satır sayısı, TSV sütunları, format parametreleri ve işaretler kontrol edilir.
- Önizleme kopyaları yalnızca `.locale_guard/` altında, atomik olarak yayımlanır.
- Sabitlenmiş SHA veya beklenen hücre/izin durumu farklıysa işlem durur.
- Mevcut `runtime_apply.py --apply` 13 runtime kararıyla ilgili **ayrı** bir sistemdir; Türkçe V3 için kullanılmamalıdır.
- Eski guard politikasında `master` ile `tr` aynılığı beklentisi mevcut olabilir. Bu politika yeniden tasarlanıp anlamsal onay verilmeden canlı Türkçe aktarımı açılmamalıdır.
